# X 随心 2.4.7-7：诊断 JSON 隔离、验收页刷新与首页添加入口

在 X 12.24.1 / iOS 17.1.1 真机上确认已安装 2.4.7-6，来源提交为 `7919d0c`。设置入口、运行状态、日志查看、脱敏保存与 USB 取回已通过。这次实测还发现三个问题：首页“添加＋”在隐藏开关开启后仍能操作；验收页周期性刷新造成位置跳动；导出自身 JSON 再进入宿主响应 hook，持续产生诊断记录，当次摘要显示 61,122 条丢弃和 128 条待写记录。

## 修复

- 验收持久化、快照、日志保留清理及脱敏导出使用线程内的本地 JSON 读取范围。宿主解析 hook 跳过这些本地数据，嵌套读取、无效 JSON 和异常后恢复原范围；真实 X 响应仍经过既有广告、分享及转推处理。
- 验收页保留非零高度估计和自适应行高。首次或行数改变才重建表格；定时更新可见单元格及标题/脚注，文本相同时不重复赋值。拖动或减速期间延期刷新，结束后补刷，以首个可见行保存位置。导出中的禁用状态及完成后的恢复也参与刷新判断。
- 首页“添加＋”的隐藏独立于私有分页器适配。只有确认推荐/关注两枚标签同排、处于小型首页表头并关联 HomeTimeline 结构后才处理该控件；关闭开关恢复。未知结构保持原布局及页面，不能承诺未知第三页已完全移除。

## 验证与待复验

新增 59 项本地 JSON 与诊断组合检查，同时启用宿主解析 hook、生产验收快照、日志清理和导出，确认本地读取不产生自身响应日志，导出不造成递归待写或丢弃。新增 23 项首页生产视图检查，覆盖已确认的首页结构、独立添加入口、恢复及未识别布局保留。

修改前 `tests/run_all.sh` 完整回归通过；针对本次修改的验收状态 113 项、本地 JSON 组合及首页检查通过。验收控制器和首页实现使用 iOS SDK、arm64 目标完成严格语法检查。这些检查不替代 UIKit 真机布局或真实宿主 hook 验收。

当前仅完成源码与本地验证，2.4.7-7 安装包尚未生成或安装。新代码的首页隐藏、验收页滚动及日志队列效果全部待真机复验；视频、图片、转推、恢复与其他尚未操作的功能仍保留待测状态。旧构建已通过的设置和日志操作不沿用为本版通过。

新包生成后覆盖升级，彻底退出并重开 X，确认运行状态和导出摘要均为 2.4.7-7，再开始新一轮验收。优先复验首页添加开关、验收页多个刷新周期与连续日志导出，记录队列是否收敛；异常时保存脱敏附件并提供复现步骤。完整流程见 [设备验收清单](DEVICE-ACCEPTANCE.md)。下一构建为 2.4.7-8。
