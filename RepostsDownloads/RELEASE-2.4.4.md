# X 随心 2.4.4：图片复制按钮精简与视频流广告过滤

## 更新

- 全屏图片复制按钮去掉文字，缩为 44×44 的图标按钮，纵向位置保留，与右侧“更多”按钮间隔 8 点。复制中、成功、失败分别用沙漏、勾号、警示图标反馈；辅助功能仍提供状态描述。长按工具箱和遮罩空白处的触摸穿透保留。
- 补齐广告过滤的数据层：在 NSJSONSerialization 解析结果交给 X 建立列表之前移除可识别的推广条目，覆盖普通 entries、视频条目、模块、增量追加和替换指令。全部由广告构成的模块移除，避免留下空模块。原生模型补充 tweet / representedStatus / itemContent 等包装路径。
- 识别依据为明确推广元数据、原生推广标记及严格匹配的推广 entryId，不根据正文含“广告”或“promoted”判断。普通视频、引用内容、分页游标、排序和未知条目保持不变；关闭“隐藏广告”后不改写响应。
- 保留 2.4.3 的原作者头像回退修复。2.4.4 可直接升级此前正式版和 2.4.3+diag.1。

## 排查依据与网上方案

本地代码缺口是：此前主要在 `TFNItemsDataViewController` 的普通时间线模型及旧视频广告开关处理，未过滤送入其他视频分页器的推广条目。这解释了为什么只隐藏普通时间线广告不足以覆盖上下滑动的视频流，但本次没有用户手机的实际广告响应，不能断言每次漏网广告都来自同一条路径。

- [BHTwitter 上游源码](https://github.com/BandarHL/BHTwitter/blob/master/Tweak.x) 使用普通时间线推广判断与 `isVideoDynamicAdEnabled` 开关。本项目保留这些已有拦截。
- [TwitterHideAds 的视频列表说明](https://github.com/MrxSiN/TwitterHideAds#what-it-removes) 将视频列表的推广条目在分页器建立前移除，并保留普通内容与游标。它是 Android 实现，本版只借鉴其数据层过滤位置和明确推广标记的思路，没有移植 Android hook 或宣称其兼容性验证适用于 iOS。

新的 iOS 实现通过 Foundation JSON 层过滤 URT 结构，并对原生模型增加包装识别。不同解析器、不同服务端实验、没有这些标记的广告和直接嵌入视频流的广告仍可能漏过，不能承诺 100% 屏蔽。请在 X 12.24.1 / iOS 17.1.1 真机刷新视频流复验。

## 安装与验证

优先安装 `XSuixin_2.4.4_rootless.deb`，彻底退出并重开 X，再进入上下滑动的视频流。确认设置中“隐藏广告”已开启。

若仍有广告，Release 也提供 `XSuixin_2.4.4_diag1_rootless.deb`（包版本 `2.4.4+diag.1`）。它包含相同修复，另外在原来的 `avatar-diag.log` 中记录 `ad_response_checked`：是否发现了相关响应、是否实际移除了条目。日志位置和导出方法见 [诊断说明](AVATAR-DIAGNOSTICS.md)。用户日志不会自动上传。

- 新增 32 项视频广告响应与模型回归检查；常规检查共 954 项通过。
- 40 项文件日志检查、诊断模式下 41 项预览检查、日志事件覆盖检查及两档真实 HLS 验证通过。
- 两种 rootless 包均完成 arm64 编译，版本/架构、最低 iOS 15.0、`/var/jb` 路径及仅 X 注入范围检查通过。
