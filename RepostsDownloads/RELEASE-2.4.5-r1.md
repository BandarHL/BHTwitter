# 2.4.5：隐藏转推整行打开详情（2026-10-02）

此前点击隐藏转推的作者区域会打开详情，点击媒体缩略图或“显示这条”却把正文展开在时间线上。本版将可见的隐藏转推卡片统一为一个“查看详情”入口，返回后继续保持隐藏。

## 修复

- 删除每个时间线控制器的 Expanded 集合及展开豁免，不再通过点击把隐藏转推改成普通时间线行。
- 整张隐藏条/缩略图卡片使用 UIControl 收拢点击，标题、头像、作者、媒体图片、空白和“查看详情”按钮统一路由。移除缩略图独立手势与按钮的展开动作，避免一个操作产生不同结果。
- 使用当前 cell 的实时 indexPath，校验当前绑定帖子与单元格关联状态后，调用原生 UITableView delegate 的行选择入口。若委托未提供方法，则只尝试同样提供该方法的宿主控制器。仅接受参数及返回类型匹配的处理器，不使用网页 URL 替代帖子详情。
- 列表正在批次更新、行已复用、帖子身份已变或原生选择方法不可用时保持隐藏并记录原因。短时间重复动作抑制；返回时间线后立即恢复点击 readiness。
- 打开详情不改变行高或重载时间线。原有详情范围逻辑继续恢复完整原生内容，返回时重新配置隐藏预览。
- 辅助功能激活沿用同一详情动作。设置中的“重新隐藏已展开的转推”改为“刷新隐藏转推显示”，清理旧展开说明。

本版基于回退后的 2.4.4 统一日志版本，不重新引入旧 2.4.5 的 SSP 广告试验代码。保留图片纯图标复制、头像处理、原有下载及广告行为。

## 日志与安装

只提供 `XSuixin_2.4.5_rootless.deb`，默认内置日志。入口为 **X 随心 → 文件与诊断 → 诊断日志（查看 / 导出）**。

新增 `repost_detail_navigation`，记录原生行选择调用、失效行及缺少可用选择处理器的原因，不记录正文。日志版本为 `build=2.4.5`、`revision=repost-details-1`。

可以从 2.4.4 升级；已装旧的 2.4.5 需重新安装本次更新后的包。安装后彻底退出并重开 X，再检查点击图片、作者和空白区域，以及详情返回后的状态。

新发布标签 `v2.4.5-r1` 对应本次源码提交，历史 `v2.4.5` 标签保留；DEB 版本仍为 2.4.5。
