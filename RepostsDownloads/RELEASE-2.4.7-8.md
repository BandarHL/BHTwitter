# X 随心 2.4.7-8：恢复推文操作栏下载按钮

用户反馈全屏视频的评论面板只有右侧独立悬浮下载按钮，推文底部的操作栏没有下载入口。本次修复使推文操作栏和悬浮按钮可以同时提供下载入口，继续只发布一个默认内置诊断日志的标准 rootless DEB。

## 原因与修复

原实现为了只保留全屏独立入口，会在开启悬浮下载时从推文操作栏的按钮数组及子视图中主动移除 `BHRDDownloadButton`；同时，全屏区域跳过了推文操作栏的自定义排列。因此已有的下载按钮即使被模型逻辑添加，也会在布局过程中消失。

- 移除布局阶段主动删除推文下载按钮的逻辑，保留当前推文模型的登记和全屏资源桥接。
- TTA / T1 两种推文操作栏均在原生布局完成后执行现有自定义排列，再匹配原生图标样式，覆盖视频评论面板内的操作栏。
- 仍由视频下载开关及原有视频/动图模型判断添加入口，并保留避免重复添加的检查。纯文字或图片回复不会因这次修复被统一加上下载按钮。
- 右侧独立悬浮下载、原生分享及图片分享入口保持原有行为。悬浮入口开关不再决定是否移除推文操作栏的下载按钮。

## 验证与发布

本地 `sh RepostsDownloads/tests/run_all.sh` 完整回归已通过，包含真实 HTTP/HLS 探测与流媒体检查；生产代码变更也完成独立审查，未发现问题。新增操作栏专项回归通过 2,688 项断言，覆盖两种宿主操作栏、全屏与普通页面、悬浮入口开关、按钮包装、可变/不可变数组及重复布局。相同检查对旧代码在“全屏且开启悬浮下载”场景明确失败，复现按钮被移除。

正式发布由 GitHub Actions 从干净提交构建 arm64 安装包，并使用 `scripts/verify_deb.py` 核验包版本、源码提交、iOS 15.0 最低版本、`/var/jb` 安装路径、仅 X 注入范围及全部代码签名页。

预期产物为 `XSuixin_2.4.7-8_rootless.deb` 及对应 `.sha256`，使用唯一标签 `v2.4.7-8`；具体检查结果、源码提交、下载附件和 SHA-256 以 [GitHub Release](https://github.com/Caun1112/BHTwitter/releases/tag/v2.4.7-8) 为准。下一安装包修订为 2.4.7-9，不覆盖已有修订的产物。

## 手机复验

本次未进行新包的真实设备安装或操作验收。本地视图夹具、语法检查和编译结果不代表 X 私有界面已在用户手机通过。

1. 覆盖升级后完全退出并重开 X，在运行状态页确认完整构建号为 2.4.7-8，并开始新一轮验收。
2. 开启视频下载与悬浮下载，打开含视频的推文并进入全屏评论面板，确认底部操作栏和右侧悬浮入口都存在，原生分享及图片分享仍可用。
3. 点击推文操作栏下载按钮，确认清晰度/媒体选择及下载使用当前推文；返回并切换其他帖子后重新测试。
4. 单独关闭悬浮入口，确认推文操作栏下载按钮仍在；关闭视频下载并重新进入帖子后，两种下载入口应按开关停用。
5. 滚动经过纯文字和图片回复，核对没有无效下载入口；检查窄屏、隐藏部分原生按钮及重复进入面板时没有重叠或重复按钮。

如果按钮仍缺失或排列异常，记录 X/iOS 版本、当前页面、相关开关状态，并从“文件与诊断”导出脱敏日志和验收报告，连同截图用于后续定位。
