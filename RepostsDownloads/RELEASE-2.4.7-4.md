# X 随心 2.4.7-4：恢复全屏右侧悬浮下载与原生参数

修复 2.4.7-3 在全屏播放时独立下载按钮消失的回归。仍提供一个标准 rootless DEB，默认内置验收页与可查看、脱敏导出的诊断日志。下一构建为 2.4.7-5。

## 具体修复

- 按钮显示与下载解析拆开：当前可见播放视图、播放控件或原生当前视频媒体即可显示，不再等 URL/variants 解析成功。加载或淡出保留，明确图片状态、离开全屏、关闭功能及模态菜单遮挡时隐藏。
- 保留右侧纯图标、44 点触摸区域、原有 65% 高度和右侧安全区内 12 点位置。既有图片复制与更多菜单继续工作。
- 当前可见的原生操作栏只读取自己的模型或适配器模型，不再作为 chrome 整棵跳过。直接使用同一帖的原生视频参数，播放器不公开资源地址也能显示分组清晰度菜单。当前 slideshow 的单个媒体也可提供参数。
- 原生参数未加载时仅复用当前非零帖子身份对应的短期缓存，并重新核对原生实体与 URL 是否仍和记录一致；不使用“最近看到的视频”。正常已确认的当前播放资源不会被旧原生模型阻断。
- 可见页、帖子和媒体身份持续核对；邻页、引用、离屏和复用后旧模型不会借用。切换、参数菜单和 HLS 返回继续校验。多视频参数菜单表示当前帖的显式选择，不擅自猜另一视频。
- 新增入口显示与布局状态基础日志。验收仍区分参数已读取、菜单实际呈现和失败原因；菜单成功不代表文件传输或相册保存完成。

## 验证与设备范围

新增夹具直接覆盖有画面但没有公开播放 URL、原生操作栏提供完整多视频参数、当前卡片媒体读取、旧参数与已确认播放 URL 冲突、图片/视频复用、清空/离屏操作栏和精确帖子参数缓存。完整回归、iOS arm64 构建与 rootless 包来源/签名核验在发布前完成。

完整回归入口通过：53 项生产全屏视图/入口证据检查、61 项媒体解析、102 项验收状态、25 项下载路由，以及既有图片保存、转推、日志、广告过滤、唯一构建身份和两档真实 HLS 检查。iOS arm64 编译、链接、签名及打包通过，保留原静态库的链接选项/段对齐警告，无编译错误。

尚未连接用户的 X 12.24.1 / iOS 17.1.1 设备，不能把本机夹具当作真机成功。安装后完全重开 X，保持下载与右侧独立入口开关开启，直接进入视频验证按钮及参数菜单，再检查选择后保存的内容。默认日志保留；异常可从验收页导出报告和诊断供下一轮修复。
