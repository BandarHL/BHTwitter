# 2.4.4 统一日志重建（2026-10-01）

按用户要求，将功能代码恢复到原 2.4.4，并默认提供日志查看和导出。只交付一个 `XSuixin_2.4.4_rootless.deb`，包版本为 2.4.4，不再区分普通版和诊断版。

## 回退范围

- Ads.x 和 RecommendationFeatures.x 与原始 2.4.4 一致；移除 2.4.5 的 BHRDAdRuntime、Google SDK 加载拦截、扩展 feature switch hook、SSP getter override 和原生 SSP 模型识别。
- 恢复原始 2.4.4 的 BHRDAdFilter；唯一额外差异是 `ad_response_seen` 观察日志，不改变过滤条件或返回结果。
- 保留 2.4.4 的图片纯图标复制、头像回退、视频下载及原有广告过滤行为。因此也可能保留原 2.4.4 的广告漏网情况，本次不作为新的广告修复发布。
- 默认日志、设置查看/刷新/导出、大小限制和临时导出快照清理保留。日志标识为 `build=2.4.4`、`revision=rollback-log-1`。

## 使用

安装后彻底退出并重开 X。已安装 2.4.5 的设备需要降级；已安装原 2.4.4 的设备需要重新安装此更新后的包。已有设置保留。

日志入口：**X 随心 → 文件与诊断 → 诊断日志（查看 / 导出）**。可查看最近 300 行，导出包含当前和上一份完整日志，不自动上传。

GitHub 修订标签为 `v2.4.4-r1`，对应此次源码提交；原 `v2.4.4` 与 `v2.4.5` 历史标签不改写。r1 是发布重建标识，DEB 内版本仍为 2.4.4。
