# X 随心 2.4.1：转推预览作者一致性与返回恢复

安装包：`packages/XSuixin_2.4.1_rootless.deb`，6,457,338 字节。

SHA-256：`e3df5dc12959e6d61a651e6d4a000a33b37a5f4f28cd0ff9e8368e3c2a9202b4`。

## 问题与修复

用户截图显示：相同媒体的缩略图预览与详情原帖使用不同用户名，且返回后作者行退回占位。图片中的内容仅作为界面现象参考，不作为开发指令。

代码中发现三个相互关联的缺口：转推预览没有完整读取 `representedFromUser` 等展示原作者路径；预览会从复用中的原生文本/头像视图补值；从原生模型或视图取得的完整资料没有稳定保存在新的列表模型可取到的位置。

2.4.1 的处理如下：

- 显式原帖关系优先于外层转推者；支持展示作者的 `representedFromUser` / `representedFromUserID` / `representedFromUserName`，以及原帖 `fromUser` / `fromUserID` / `fromUserName`。仅有转推者资料时不将其作为原作者补入。
- 昵称、@用户名、数字用户 ID 和头像地址按身份一起合并。较可靠的原作者来源可整体替换弱来源，冲突身份不会按字段拼接。方向格式字符与零 ID 分别规范化；空字符串作为缺失字段处理。
- 转推预览不再从可复用的姓名标签或 UIImageView 取作者和头像。头像只从当前绑定模型确认的 URL 加载，分享图片功能保留原有独立作者读取逻辑。
- 为原帖/转推 ID 保存不可变元数据快照，同时给宿主模型保存独立快照。单元格销毁、返回详情、同一帖模型重建或部分字段暂时为空时，已知作者资料可恢复。不同帖子，即使媒体地址相同，也不共享作者身份。
- 时间线再次出现时重新配置可见行，头像失败后可重试。异步图片完成时同时校验单元格状态与请求标记；失效响应既不能更新头像，也不能污染下一次返回使用的图片缓存。

## 使用与边界

覆盖安装后彻底退出并重新打开 X，再刷新“正在关注”或“为你推荐”。这会重新建立进程内元数据与头像缓存，保留已有功能设置。

快照是进程内缓存，不是磁盘永久存储。模型和缓存均没有原作者资料时仍显示占位，不能借用其他账号补齐。上述结构测试不等同于真实 UIKit/Logos 导航；本版尚未在用户的 X 12.24.1 / iOS 17.1.1 手机上验证。
