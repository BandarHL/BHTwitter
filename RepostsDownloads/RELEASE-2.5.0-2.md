# X 随心 2.5.0-2：实机审计后的可靠性修订

以 2.5.0-1 / `3b797d4` 为正式基线。用户报告在 X 12.24.1 / iOS 17.1.1 上确认：两个全屏视频仍解析失败、首页添加入口仍可打开；单张当前图复制、分享 PNG 和短性能样本判据已通过。报告及截图仅留在本地，没有将含浏览内容的附件提交到仓库。

## 本次处理

- **F1 视频**：基础日志新增 `resourceDecisionCounts`，区分 scheme、host、扩展名、MIME 拒绝，不记录地址或身份，也不依赖详细模式。当前摘要不足以确认两个失败视频的具体资源格式，因此本版没有放宽来源限制或伪造资源转换，**不能宣称这两个实机视频的下载已经修复**。下一次相同场景失败可直接提供明确分类。
- **F2 首页**：支持有可访问性标签的普通/Swift 控件，并处理位于已确认首页表头末端的加号与小型 CollectionView 单元格；隐藏整个可选择命中区域。无关加号、帖子内按钮及未知页面继续保留。新增有界扫描及拒绝原因日志，区分标签、首页控制器、共同表头、候选几何、命中目标与分页器识别。Add隐藏与第三页限制分别验收，未知第三页不按下标删除；**本版实机效果待复验**。
- **S1 隐私出口**：诊断导出使用已知事件、事件字段集合、固定词汇、数值范围及受控路径结构。未知事件只输出有效构建元数据；历史 `user_id/statusID/tweet_id/id_str/account`、嵌套未知字段和自由文本不导出；未知错误域归为固定类别。原始日志仍仅在本机。修复日志尾行缺换行时下一条记录被拼接的问题。
- **S2 探测取消**：HLS清晰度探测每秒在主线程公共运行模式检查当前选择，失效或读取异常时停止引擎、HUD、定时器并释放名额；回调再次验证。已确认的下载继续运行，不因翻页一律取消。
- **S3/S5 分享**：高清图改为逐块接收，单图12 MiB、同代累计24 MiB、32 MP像素上限，最多两路并发；检查HTTPS来源、HTTP状态、MIME和重定向。旧代/关闭后数据不进入缓存。分享页复用复制读回校验及本机/过期偏好；相册提交前关闭可取消，提交后保留真实结果；系统分享区分完成、取消、错误并清理临时文件。
- **S4/S8 状态**：人工评价独立保存为未评价/通过/失败，普通采样、停止或重新采样不抹去人工失败；告警优先于人工通过。只有开始新验收轮次才清除意见和告警。暂停变化刷新设置，写入入口再次核对本次启动是否实际加载功能。
- **CI**：main/PR也完整编译UIKit和Logos生产代码；标签继续执行包身份、源码仓库/提交、rootless路径及签名页核验。

## 自动验证与边界

针对性检查覆盖首页真实视图命中、四类资源拒绝、日志出口反例、HLS生产任务编排、真实HTTP流式接收、Photos授权/关闭/回调竞态、人工意见及安全启动设置门控。本地完整回归已通过，包括131项验收、27项首页视图、98项媒体解析、19项严格出口、75项诊断日志、28项生产探测生命周期、67项流式接收及58项分享导出检查；修改后的生产文件完成iOS arm64语法检查。完整生产编译及包核验以本次Release对应Actions结果为准。原生 FFmpegKit、Photos和UIKit在部分宿主测试中使用替身；测试通过不等于iOS实机端到端通过。

本轮未连接手机安装验证。报告中的 S6（MP4可播放性检查）、S7（复杂图片选择截断/歧义）、S9（更完整ABI、过滤反例、恢复重试及临时附件启动清理）仍是后续工作；没有借此改动广告过滤策略，也未声称解决内存泄漏或耗电。

## 安装后优先复验

确认版本2.5.0-2、源码仓库Caun1112/XSuixin，完全退出重开X。先用报告中相同的两条视频与连续第三条视频测试，核对真实文件内容/时长/分辨率/音轨；失败时导出新 `resourceDecisionCounts`。首页开关开启后检查加号不可见且不可命中，关闭后恢复；第三页另测。

HLS探测期间翻页或退出，应在约1秒检查周期内取消并释放名额；已确认下载可继续。复制在接收App前台粘贴核对；测试分享页关闭、权限拒绝和错误反馈。人工标记失败后继续采样/停止，结果应保留；实际告警后人工通过不能掩盖告警。保持20分钟前台及后台切换、转推和文件保留等未完成验收项目为待验。
