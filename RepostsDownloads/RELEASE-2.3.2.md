# X 随心 2.3.2

## 变更范围

按用户要求撤回 2.3.1 的全部 BetterX 广告适配。删除新增的广告视图扫描、标签变更观察、广告证据缓存、独立卡片恢复逻辑，以及相关测试和许可资源。广告模型判断、Premium 及广告 feature-switch、列表呈现、设置开关语义和编译源文件列表恢复至 2.3.0。

保留全屏下载按钮图标样式：无“下载”文字，44×44 点按钮，横竖屏的中心位置均与原按钮一致，纵向仍位于屏幕高度 65%。保留无障碍名称和原有下载功能。

除这两个图标/几何实现文件和设置页版本文字外，所有顶层生产 `.m`、`.h`、`.x` 文件及 Makefile 已逐文件核对，与提交 `8b4440d`（2.3.0）一致。未修改用户工作区根目录已有的 BHTwitter 改动。

## 验证边界

本次是完整撤回新增广告代码，不是依据真机日志定位根因。尚未在用户手机上验证启动恢复情况。覆盖安装后请彻底退出并重新打开 X，现有设置保留。
