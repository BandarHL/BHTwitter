## 修复内容

针对昵称与用户名已经正确显示、头像仍为占位图的反馈，修复以下可复现的代码缺口。截图仅作为界面现象参考，不能确认手机实际采用哪种模型字段。

- 展示作者资料不完整时，允许同 ID（或双方没有冲突 ID 且用户名匹配）的原始用户资料补齐头像。不同 ID 即使用户名相同也不合并；原帖优先规则保持有效。
- 先解析用户包装对象内的身份，再核对是否属于原作者，避免完整头像存在于包装对象内却被提前跳过。
- 补充原生头像资源/请求包装、展示作者状态字段、旧式 `profile_image_url`，仅接受指定 Twitter 头像路径；旧 HTTP 地址升级为 HTTPS。媒体图片、其他域名、带凭据或自定义端口的地址不会被当作头像。
- 分开返回的用户资料可按规范化用户名补齐尚无数字 ID 的作者。数字 ID 冲突仍拒绝关联。当前可见预览会在资料到达时重新配置。
- 缺少 MIME 或使用二进制 MIME 的响应也尝试图片解码，保留 HTTP 状态、数据长度和解码校验。头像失败后当前可见行最多自动重试两次，延迟分别为 1 秒、3 秒。
- 继续保留单元格与请求标记双重校验。过期响应、复用前安排的重试不能覆盖当前作者头像；不从附近原生头像视图借用未验证的像素。
