# X 随心 2.4.7-2：实际运行验收与反馈

新增“X 随心 → 运行状态与恢复 → 实际运行验收”。开始一轮后，回到 X 实际操作，再查看结果或导出报告与脱敏日志。继续只提供一个默认带诊断日志的 rootless DEB。

## 实际观察

- 记录照片添加权限、原图取得/数据校验、Photos 提交与完成回调；切图、退出或主动取消分开记录。保存当前图回退属于同一次操作。系统写入成功后仍需人工核对图片内容、方向与质量。
- 三指长按恢复菜单实际展示才确认手势。暂停启动自动弹出的菜单不充当手势证据。暂停/恢复标记写入后保持等待，下一个进程启动才能确认跳过或启用功能。
- 隐藏转推原生选择回调仅为“已请求”。详情出现需匹配原帖身份，返回需找到对应可见行且原生内容仍隐藏才确认。错误详情身份明确报告，未知身份、目标行不可见和确认超时保留待验证。
- 用户主动启动性能观察，离开页面可以继续浏览 X，后台暂停，20 分钟自动停止。记录显示回调间隔、进程内存及采样峰值、热状态与内存警告；不把正常采样自动判为性能通过，不测视频真实 FPS 或耗电。
- 项目可以人工确认或报告问题，来源明确。成功/失败/取消计数分别保留。验收轮次跨重启保存，按构建和源码提交隔离，旧轮次的异步结果不污染新轮次。
- 报告、性能 JSON 与脱敏日志可通过系统分享保存/发送。记录生成、展示、分享完成/取消/失败；系统活动完成不证明接收端收到。验收状态不依赖日志队列容量，队列丢弃仍保留关键观察。

## 验证与边界

新增验收状态、损坏持久化输入与隐私白名单、性能统计和详情事件关联的回归检查。完整测试入口为 `sh RepostsDownloads/tests/run_all.sh`；构建核验要求验收页、记录存储、性能监测、默认日志及准确干净提交存在，并检查 rootless 路径、架构和全部签名页。

完整测试入口已通过，新增 68 项验收状态、28 项性能统计和 23 项实际生产详情事件夹具检查；67 项日志管理检查包括队列丢弃不丢验收结果。既有照片权限/保存、视图和广告回归、唯一版本身份及两档真实 HLS 校验通过。iOS arm64 严格语法检查及 Theos 编译、链接、签名与打包完成。链接器仍输出原 FFmpeg 静态库的旧选项/对齐警告，没有编译错误。

这些检查在本机夹具和 iOS 编译环境完成，不能代表用户手机已验收。页面就是用于记录用户的实际运行结果，异常时导出并回传后继续下一构建修订。X 启动前崩溃、不可读取的私有模型、图片质量与实际耗电仍需要用户或系统报告补充。广告保持已有推广过滤及部分覆盖边界，没有重新加入 SSP 试验拦截。

正式附件由干净的 GitHub 来源提交构建。Release 配对完整构建 `2.4.7-2`、源码提交与 SHA-256；下一安装包使用 `2.4.7-3`，不覆盖旧构建。
