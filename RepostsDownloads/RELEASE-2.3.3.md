# X 随心 2.3.3：全屏复制图片

安装包：`packages/XSuixin_2.3.3_rootless.deb`（6,446,546 字节）。

SHA-256：`c2e5166d9b2251ca7f847815ec05fe9442934af96d5936ac165ea080c9087ee9`。

## 使用

点开图片进入全屏查看器，点击右侧“复制图片”，再到支持粘贴图片的应用粘贴。优先复制图片原始数据；网络失败时使用当前已加载的图片，并显示“已复制当前图”。不保存相册、不请求相册权限。图片复制独立于视频下载开关。

视频保留 2.3.2 的图标下载按钮。切换到图片时显示复制按钮，回到视频时恢复视频按钮。复制按钮之外的滑动、缩放等手势仍由原生界面处理。

## 实现与范围

- 仅在已识别的 Slideshow/PhotoViewer/ImageViewer 全屏控制器内工作；通过当前可见图片视图读取地址或已加载位图。
- 参考 hoothin 的 X-Downloader-Script（2025-08-18，MIT）原图地址处理逻辑，将旧式尺寸后缀及现代 `name` 参数改为原图请求。
- 不嵌入或执行浏览器脚本，不调用脚本中的第三方视频下载服务。BetterX 广告代码仍保持撤回状态，广告相关代码与 2.3.2 一致。
- 点击时才联网，使用临时 URLSession、30 秒资源超时、32 MiB 数据上限、HTTP/图片格式验证。以实际图像类型写入剪贴板；没有原图地址或获取失败时使用已加载位图。
- 全屏内每 0.4 秒观察当前图片，离开页面后停止。选择中央可见媒体，优先真实媒体 URL，排除背景、离屏图片、状态说明区域、视频封面和活动视频播放器。
- 翻页、退出或出现模态页面会使旧请求失效，旧结果不能覆盖剪贴板。不存在保存到相册的新增路径。

## 验证

原有 734 项回归检查通过；新增 30 项原图地址/数据类型/网络请求/取消检查、11 项直接调用生产全屏选择器的结构检查，共 **775 项**。另有两档真实 HLS 下载的分辨率、音频与解码帧一致性验证通过。

正式 arm64 编译与 rootless 打包通过：版本 2.3.3、架构 iphoneos-arm64、最低 iOS 15.0、安装路径 /var/jb、仅注入 X；两份 CodeDirectory 的 **8,038 个代码页哈希**核验通过。包内确认包含图片复制类及许可说明，不含 BetterX 新增广告类或诊断标记。链接器保留旧依赖的废弃参数及节对齐提示，无编译错误。

## 验证边界

尚未在用户手机的 X 中验证真实控制器/视图结构、按钮呈现和跨应用粘贴。视图测试使用 macOS 最小夹具，不能替代 UIKit/Logos 真机测试。未暴露可识别地址但有已加载位图时复制该位图；未知查看器或媒体视图结构可能无法显示按钮。原图不可用时会明确提示使用当前图片。

覆盖安装后完全退出并重开 X，点开一张图片测试复制和粘贴。
