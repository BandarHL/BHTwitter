# X 随心 2.3.0 发布核验

安装文件：`packages/XSuixin_2.3.0_rootless.deb`（6,441,846 字节）。

SHA-256：`86510e29455e328564a343cd0ed8d2d9eb2ac6babb495b98d4059810ce533dc3`。

适用于标准 rootless 越狱环境；包架构 `iphoneos-arm64`，动态库 `arm64`，最低 iOS 15.0，安装前缀 `/var/jb`。与 BHTwitter 完整版和 Hide Reposts 独立版的冲突声明保留。

## 审查问题与处理

| 原问题 | 2.3.0 处理 | 主要验证 |
|---|---|---|
| 1. 包装模型漏过滤 | 三类过滤统一使用 `BHRDUnwrapModel`，展开身份也从内层读取 | 包装转推/广告、普通帖负例 |
| 2. 转推作者混配 | 缺少数字 ID 时核验用户名冲突 | Alice/Bob 混配及大小写匹配 |
| 3. 分享头像绕过校验 | 移除旧坐标头像/作者兜底，详情表头调用同一作者解析器 | 7 项直接执行生产视图补齐代码的结构测试 |
| 4. 导出旧 PNG | 图片更新立即使渲染代次失效，仅最新代次解锁导出 | 图片到达、旧回调、主题切换、保存互斥 |
| 5. 隐藏图片阻塞导出 | 仅加载实际绘制的正文、作者和引用媒体，开关变化取消旧请求 | 各显示组合的资源依赖 |
| 6. 清晰度选择变转码 | 使用 FFprobe stream index，视频与音频 remux，不缩放、不降码率 | 两档真实 HLS，分辨率/音频/解码帧核对 |
| 7. 流媒体脱离任务状态 | 下载阶段返回任务并通知结束；普通视频与流媒体共用准入 | 多 owner 互斥、真实并发 HTTP 拒绝、取消后重启 |
| 8. 保留文件无入口 | 专属目录与下载文件列表，可保存、分享、删除，7 天清理 | 文件完成落盘、过期、活跃任务和路径别名保护 |
| 9. 旧长正文覆盖新全文 | 按全文/长文来源及显式截断标记合并，同级旧缓存只补缺 | 更短新全文、缓存更新、截断刷新 |
| 10. 刷新标记卡住 | 延迟回调先清除排队/强刷标记，再检查详情范围 | 代码路径审查、iOS arm64 编译 |
| 11. 标签与分页错位 | 依据页面身份选择并排序，无法可靠识别则保留原生分页 | 页面重排、身份缺失和歧义 |
| 12. 无效后台/滚动开销 | 按启用功能缓存 JSON，停用推荐直接返回，移除 KVC 异常探测 | 无未知字段异常、代码路径审查 |
| 13. 测试覆盖缺口 | 增加生产渲染状态、作者视图结构、真实 HTTP/HLS 和包签名验证 | 统一 `tests/run_all.sh` |
| 14. 未入版本管理/CI 不构建插件 | 独立源码、测试、文档加入 Git；新增专属 GitHub Actions，固定 Theos/SDK 提交 | 本地执行相同测试、构建和校验命令 |

## 本地验证

- 原有 687 项检查继续通过，实际 HTTP 生命周期检查增加 3 项；新发布回归 37 项、生产作者视图结构检查 7 项，总计 **734 项检查**。
- 另外运行 **2 档真实 HLS 样例**，两种分辨率分别选择成功，保留音频，解码后每帧校验值与源流一致。
- 正式 arm64 编译和 rootless 打包通过；正式包不含 `XSuixinDiag` 诊断标记。
- 两份 CodeDirectory 的 **8,022 个代码页哈希**均验证通过。
- 链接器沿用旧静态依赖的两条提示：废弃的 `-multiply_defined` 参数，以及 `__common` 节对齐从 0x8000 调整为 0x4000；未产生编译错误，包内签名完整性通过。
