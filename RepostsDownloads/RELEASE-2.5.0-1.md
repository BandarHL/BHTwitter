# X 随心 2.5.0（构建 2.5.0-1）

本版解决正式仓库停留旧代码的问题，并修正图片复制成功判定、普通日志频繁写入和性能样本状态。正式源码在 `Caun1112/XSuixin` 的 `main`，发布标签为 `v2.5.0-1`；保留原有仓库历史。完整 Debian 修订为 2.5.0-1，下一个不同源码包使用新修订。

## 版本差异的原因

2026-10-20 核对时，XSuixin/main 为 `7919d0c`（2.4.7-6）。此前 2.4.7-8 发布于另一个仓库 Caun1112/BHTwitter，标签源码为 `f02b0cd`；后续工作分支到达 `5248612`。因此手机对 XSuixin/main 的旧版本判断成立。本版同步 RepostsDownloads 产品源码及测试，包含 2.4.7-7、2.4.7-8 和后续视频诊断；不覆盖旧 Release，也不重写历史标签。

## 修复

- 推文操作栏与右侧悬浮下载共存；保留 TTA/T1 两种布局及原生分享。继承本地 JSON 读取隔离、验收页原地刷新、首页添加入口修复和图片诊断。
- 图片复制先验证有效图像，再核对剪贴板 changeCount、实际图片类型、读回字节及读取期间的版本。写入拒绝、清空、替换、读写异常都返回失败；无效图不清空原剪贴板，不覆盖随后发生的其他写入。链接复制也核对本次结果。当前图复制保持离线，不以联网下载补偿失败。
- 普通广告未命中保留首条，其余按计数/字节数汇总，最多一个等待回调；查看和导出前刷新。失败与命中逐条保留，主动聚合数和真实丢弃数分开。原广告过滤策略不变。
- 性能统计和验收状态共用 30 秒前台/120 回调门槛，停止但不足显示待验证；新轮次清除旧样本。足量观察仍需人工确认，内存警告仍保留失败状态。
- 同步有界视频资源诊断；资源拒绝类别在脱敏导出中保留，地址仍删除。保留 TAV 当前项匹配、MP4/HLS 参数、切换取消、超时和严格来源校验，不凭截图猜测新的私有字段。
- 运行状态和日志包含源码仓库，包核验可验证仓库/提交。main 与 PR 跑完整回归，标签构建验证后自动发布同版本说明、DEB 和 SHA-256，避免源码首页与发布身份混淆。

## 验证边界

本地完整回归已通过，修改的生产实现完成 iOS arm64 语法检查。剪贴板/工具检查 51 项、验收状态 119 项、诊断日志 74 项、生产操作栏检查 2,688 项通过。

回归覆盖剪贴板拒绝/清空/替换/异常、10,000 条并发普通日志汇总及失败保留、真实队列溢出单独计数、本地 JSON 不回灌、性能样本边界/新轮次，以及既有视频切换、HLS、图片解析和操作栏布局。完整执行结果与构建 SHA 以本 Release 对应的 GitHub Actions 为准。测试夹具用于复现故障条件，不冒充来自本次手机的原始失败数据。

CI 核验 arm64、iOS 15.0、标准 /var/jb 路径、仅 X 注入、构建版本/提交/仓库、2.5.0 功能标记与全部签名页。尚无本版真实设备安装记录，不能保证未知 X 版本的全部私有接口可用，也不能据此认定此前剪贴板问题的唯一成因、内存泄漏或卡顿根因。

## 安装后复验

覆盖升级后彻底退出并重开 X，确认运行状态为 `2.5.0-1`、仓库为 `Caun1112/XSuixin`。检查推文与悬浮下载都可用，普通/HLS/连续第三条视频下载的文件内容正确；首张、后续、大图和快速翻页后，在其他 App 实际粘贴核对图片及尺寸。短时间停止性能观察应显示样本不足。导出诊断检查聚合数和真实丢弃数，详细步骤见 [设备验收](DEVICE-ACCEPTANCE.md)。
